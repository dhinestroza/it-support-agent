# Email and shared folder access requests

## When this applies
Use this guide when an employee requests access to a shared mailbox, a
distribution list, or a shared drive/folder they don't currently have
permission for.

## Standard access requests
Requests for access to a shared folder or distribution list within the
employee's own department are pre-approved and can be granted directly,
as long as the employee's manager is CC'd on the request (or the request
explicitly states the manager already approved it).

## Cross-department or sensitive folder requests
Any request for access to a folder or mailbox outside the employee's own
department, or to anything marked confidential/restricted, requires
explicit written approval from that folder's owner — this cannot be
granted from this guide alone.

## When to escalate
Escalate any request that involves: access to finance, HR, or legal
shared drives; a distribution list with external (non-employee)
recipients; or any request where the employee doesn't name their manager
or the folder owner.
