# Hardware requests

## When this applies
Use this guide when an employee asks for new hardware: a replacement
laptop, a monitor, a keyboard/mouse, or similar equipment.

## What can be answered directly
General questions about the request process, expected lead times
(standard equipment ships within 5 business days), and how to check the
status of an already-submitted request can be answered directly from this
guide.

## What always requires escalation
Any actual approval or purchase of new hardware is outside this agent's
authority and always requires escalation to a human. This includes new
laptop requests, monitor requests, and any equipment above standard
issue (e.g. specialized peripherals). The agent can draft the request
summary for the human reviewer, but cannot approve it.
