# Non-standard software installation

## When this applies
Use this guide when an employee wants software installed that isn't part
of the standard company image (standard image includes the OS, browser,
email client, and office suite — anything beyond that is non-standard).

## Pre-approved software
A short list of pre-approved tools (listed in the internal software
catalog at `https://software.internal.company.com/catalog`) can be
self-installed by the employee without IT approval — this guide can point
the employee to that catalog and confirm whether a specific tool is on
it, if the tool name is stated in the ticket.

## Everything else
Any software not on the pre-approved catalog requires a security review
before installation — this cannot be resolved directly. Escalate with the
software name and the business justification, if the employee provided
one.
